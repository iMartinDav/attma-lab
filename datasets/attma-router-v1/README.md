# Dataset Card: iMartinDav/attma-router-v1

**Research-use only. No real patient data, no real genomes, no real names.**

## Summary

Routing prompts for the Attma Router: a LoRA fine-tune of Muse Glimmer 30B that routes a request to one of seven pipelines and returns strict JSON. Each row is a synthetic prompt generated programmatically from hand-written templates + fictional slots, with a gold route, complexity, confidence, and reason.

- **Routes:** `germline | somatic | infectious | pgx | biosecurity_review | biosecurity_refuse | human_escalate`
- **Version v0.3 (built 21 Nov 2026): 1,680 prompts, 240 per route** — generated by `datasets/build_router_dataset.py` (seed 7). Files in `data/`: `all.jsonl`, `train.jsonl`, `validation.jsonl`, `test.jsonl`, `manifest.json`, plus chat-format SFT files `train_sft.jsonl`, `validation_sft.jsonl`, `test_sft.jsonl` built by `experiments/attma-router/build_sft_data.py` (system prompt verbatim from `run_router_bench.py:SYSTEM`, assistant = strict JSON, loss on the assistant turn only).
- **Target size (v1):** 2,000–5,000 prompts, held-out test split **n≥500**. v0.3 is the training-ready seed, not the final dataset.

## Schema

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique row id, e.g. `router-0001` |
| `prompt` | string | The user request (synthetic; no real patient text) |
| `route` | string | Gold route (one of the seven above) |
| `complexity` | string | `low \| medium \| high` |
| `confidence` | float | Annotator confidence 0.0–1.0 |
| `reason` | string | Short reason for the route (one sentence) |
| `source` | string | `synthetic` |
| `disease_area` | string | e.g. `neurodevelopmental`, `oncology`, `infectious`, `none` |
| `topic_family` | string | Topic family, e.g. `neurodevelopmental`, `solid-tumour` — the split key |

## Generation method

- 84 hand-written templates (12 per route, 6 topic families per
  route), each with fictional slot values (diseases, genes, assays,
  phenotypes, drugs). Slot combinations × 5 neutral context variants
  × phrasing variants for low-combination templates, capped at 20
  rows per template for balance, de-duplicated, shuffled with seed 7.
- Builder: `datasets/build_router_dataset.py`. Re-run it to
  regenerate the dataset exactly: `python datasets/build_router_dataset.py`.
- The 20-row seed in `experiments/attma-router/data/router_seed.jsonl`
  is a schema demo only; it is not part of v0.3.

## Sources and licences

- Synthetic prompts written for this lab (CC-BY-4.0, as part of this dataset).
- Public clinical-genomics documentation used only as inspiration for prompt topics — no text copied verbatim from any patient record.
- No ClinVar / gnomAD / HPO data is copied into this dataset; those sources are used only for the Ranker dataset.

## Splits and leakage controls

- **Splits and leakage controls**

- **Train / validation / test, stratified by (route, topic_family)** — 1 family per route to test, 1 to validation, 4 to train; no topic family appears in more than one split (verified: family overlap between splits is empty).
- Test split is held out: never used for training, prompt selection, or hyperparameter tuning.
- Seed (7) is fixed and recorded in `data/manifest.json`.

## Intended use

Training and evaluating the Attma Router only. Research-use only. Not for diagnosis, treatment decisions, or any clinical use.

## Limitations

- Template-generated prompts do not cover the full diversity of real lab requests; real-world routing accuracy will differ, and will be lower on phrasings and topics outside the template families.
- The v0.2 test split covered only 4 of 7 routes (fixed in v0.3 by
  the stratified split; see table above).
- Biosecurity rows test *intent* only; they contain no instructions for wrongdoing, no protocols, and no sequences.
- Confidence values are annotator judgements, not calibrated probabilities.

## Version

v0.3 — 1,680 template-generated rows (21 Nov 2026), stratified split
(all 7 routes in every split) + chat-format SFT files. v0.2 was the
same 1,680 rows with the unstratified split (test covered 4 routes).
v0.1 was seed schema only.
